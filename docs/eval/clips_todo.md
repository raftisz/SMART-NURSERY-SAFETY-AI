# คลิป QA ที่ยังต้องถ่าย (สถานะ 2026-10-10)

รายการเต็มและวิธีถ่ายอยู่ใน `docs/eval/qa_shooting_script.md` เอกสารนี้สรุปแค่ว่า **ยังขาดอะไร** เทียบกับคลิปที่มีใน `~/qa_clips`
เกณฑ์ของ out_of_area และ fight อยู่ใน `docs/eval/decision_gates_outarea_fight.md` (ล็อกไว้ ห้ามแก้หลังเห็นผล)

## ที่มีแล้ว

`~/qa_clips` มี 7 คลิป ทั้งหมดเป็น outarea รอบ s1:
`outarea_pos_s1_01..04` และ `outarea_neg_s1_01`, `_02`, `_04`

ข้อควรรู้ของ 7 คลิปนี้:
- ไฟล์มีป้ายหมุน 180° (ถือมือถือกลับหัว) ก่อนแก้ `CameraSource` ระบบเห็นภาพกลับหัว ตอนนี้หมุนให้แล้ว
  แต่โซนที่เคยวาดบนภาพกลับหัวใช้ไม่ได้ ต้องวาดใหม่
- กล้องตั้งต่ำและใกล้ หลายคลิปมองไม่เห็นเท้า (กรอบคนชนขอบล่าง) กฎ out_of_area ข้ามกรอบแบบนี้โดยตั้งใจ
  ถ้าจะใช้วัดจริง ควรถ่ายใหม่ให้เห็นพื้นและเท้าครบ

## สิ่งที่เรียนรู้จากการทดสอบเบื้องต้น (ใช้ตอนถ่าย)

- **ถือกล้องแนวนอน ด้านบนขึ้น** ระบบหมุนภาพตามป้ายของไฟล์ได้แล้ว แต่ถ่ายให้ถูกทิศตั้งแต่ต้นปลอดภัยกว่า
- **outarea:** ตั้งกล้องสูงกว่าระดับเอว เฉียงลงพื้น ต้องเห็นเท้าของคนในโซนทุกจุด ไม่ให้กรอบคนชนขอบล่าง
- **fight:** ถ่ายแนวนอน ให้เห็นทั้งสองคนเต็มตัวตลอดคลิป คลิปแนวตั้งหรือกรอบแคบมักเห็นคนเดียว จึงวัดไม่ได้
- ทุกคลิปที่มีคนต้องเป็นผู้ใหญ่ และห้ามนำคลิปขึ้น GitHub หรือส่งออกนอกเครื่อง
