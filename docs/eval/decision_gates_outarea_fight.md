# Decision Gate: out_of_area และ fight

- **อนุมัติ:** 2026-10-04 โดยเจ้าของโปรเจกต์
- **ตั้งก่อนเห็นผล:** ตั้งก่อนเห็นผลวัดของคลิปรอบ s2 (ชุดวัดผล) ห้ามแก้เกณฑ์หลังจากเห็นผลแล้ว
- เกณฑ์นี้แยกจาก Decision Gate ของ Phase 2 ใน README (กรรไกร/มีด/ความเร็ว) ซึ่งไม่ได้เปลี่ยน

## เกณฑ์

1 คลิป = 1 ครั้งทดลอง ใช้คลิปรอบ **s2** เท่านั้น ถ้าจำนวนคลิปไม่ครบตามที่กำหนด ผลเป็น **ยังไม่ครบ** ไม่ใช่ผ่าน

| module | กลุ่มคลิป | ผ่านเมื่อ |
|---|---|---|
| out_of_area | ผู้ใหญ่**ย่อตัว**อยู่ในโซนนานกว่า 3 วินาที (แทนเด็ก) | แจ้งเตือน **≥ 8/10** คลิป |
| out_of_area | ผู้ใหญ่**ยืนตรง**ในโซน | แจ้งผิด **≤ 1/10** คลิป |
| out_of_area | ผู้ใหญ่ย่อตัว**ผ่านโซนเร็ว** น้อยกว่า 2 วินาที | ไม่แจ้งเตือน **≥ 9/10** คลิป |
| fight | **แสดง**การทะเลาะ (เบา ๆ ตามกฎความปลอดภัย) | แจ้งเตือน **≥ 4/6** คลิป |
| fight | กิจกรรมปกติ: กอด, ไฮไฟว์, เต้น, คุย (อย่างละ 2) | แจ้งผิด **≤ 2/8** คลิป |

"แจ้งเตือน" = มีเหตุการณ์ประเภทนั้นอย่างน้อย 1 ครั้งในคลิป (CONFIRMED หรือ SUPPRESSED) นับโดย `tools/eval_clips.py`

## วิธีวัด

```bash
python tools/eval_clips.py --labels docs/eval/qa_labels.csv --split test \
    --modules hazard_object,climbing_pose --tag gate_s2
```

- `hazard_object` ให้กรอบ person กับ out_of_area ส่วน `climbing_pose` ให้ keypoint กับ fight จึงต้องเปิดทั้งสอง module
- โซนของกล้อง `qa` ต้องวาดและปรับเทียบจากคลิป `calib_outarea_s2.mp4` (ถ้าไม่ได้ย้ายกล้องหลังรอบ s1 ใช้โซนเดิมได้) การปรับเทียบไม่ใช่การปรับค่า จึงทำได้ก่อนวัดผล
- ชื่อคลิปและจำนวนต่อกลุ่มอยู่ใน `docs/eval/qa_shooting_script.md` หัวข้อรอบ s2

## ข้อจำกัดที่ต้องรายงานคู่กับผล

- ใช้ผู้ใหญ่ย่อตัวแทนเด็ก ไม่มีข้อมูลเด็กจริง
- การทะเลาะเป็นการแสดง ช้าและเบากว่าของจริง
- จำนวนคลิปน้อย (6–10 ต่อกลุ่ม) ผลบอกได้แค่ผ่านหรือไม่ผ่านเกณฑ์นี้ ไม่ใช่อัตราความแม่นยำที่ใช้กับทุกสถานการณ์
