# hazard_object v1: ข้อมูลที่ใช้ fine-tune และวิธีกันตัวเลขหลอกตา

> เอกสารนี้อธิบาย**ข้อมูล**และ**วิธีวัด** ส่วนผลก่อน→หลัง อยู่ใน `hazard_v1_full_eval.md` (Colab, GPU)
> ภาพทั้งหมดเป็นภาพจากเว็บ / COCO **ไม่ใช่กล้องของเนอสเซอรี่** ตัวเลขใช้จัดอันดับโมเดล
> ไม่ได้แทน Decision Gate ของ Phase 2 หรือคลิป QA (`tools/eval_clips.py`)

## 1. แหล่งข้อมูล

ภาพปืนอย่างเดียว (pistol) ถูกตัดออก ไม่ใช่ของในเนอสเซอรี่

**ไม่มีชุดข้อมูล "คัตเตอร์" ที่เข้าถึงได้แบบเปิด** จึงยังไม่ได้เพิ่มคลาส `cutter` (ข้อจำกัดเดิมใน README ยังอยู่)

## 2. ทำไมเทรน 80 คลาส ไม่ใช่ 3 คลาส

ข้อมูลใหม่มีป้ายแค่ `knife` (และ `cell phone`) ถ้าเปลี่ยนหัวเป็น 3 คลาส Ultralytics จะสุ่มหัวใหม่
โมเดลต้องเรียน `scissors` ใหม่จากภาพ COCO กรรไกรไม่กี่สิบภาพ → กรรไกร (คลาสหลักของ Gate) จะแย่ลง
จึงคงหัว COCO 80 คลาสไว้ แล้วให้ **YOLO11-L/X (teacher)** ติดป้ายคลาสอื่นในภาพเว็บ (knowledge distillation)

## 3. กฎติดป้าย (ทดสอบใน `tests/test_build_hazard_dataset.py`)

- GT ของแหล่งข้อมูลชนะเสมอ
- กล่องของ teacher ที่ทับ GT คลาสอื่น (IoU ≥ 0.3) ถูกทิ้ง
  **เหตุผล:** ในการสร้างครั้งแรก teacher ติด `scissors` 413 กล่อง ในภาพมีด **363 กล่องทับมีดที่มี GT อยู่แล้ว**
  = teacher สับสนมีด/กรรไกรเอง ถ้าไม่ทิ้ง โมเดลจะถูกสอนให้สับสนตาม
  (ชุดที่สร้างก่อนมีกฎนี้แก้ด้วย `tools/fix_pseudo_labels.py`)
- มีดที่เว็บไม่ได้ติดป้าย (ตรวจด้วยตา: มีด 2 เล่มบนโต๊ะ ติดป้ายเล่มเดียว) เติมจาก teacher เฉพาะ conf ≥ 0.6 และไม่ทับของเดิม
- **ชุดทดสอบใช้ GT อย่างเดียว ไม่เติมจาก teacher** เพื่อไม่ให้ผลเข้าข้างโมเดลที่คิดเหมือน teacher

## 4. กันข้อมูลรั่ว (leakage)

- HOD: ภาพเกือบซ้ำ (dHash ต่างกัน ≤ 6/64 bit) **3,186 ภาพ รวมเป็น 2,700 กลุ่ม** = ภาพซ้ำราว 490 ภาพ
  ทั้งกลุ่มอยู่ split เดียวกันเสมอ ถ้าไม่ทำ ภาพเดียวกันจะอยู่ทั้งชุดเทรนและชุดทดสอบ ตัวเลขจะสูงเกินจริง
- Sohas: ใช้ train/test ของผู้สร้างชุดข้อมูล เฟรมจากคลิปเดียวกันอยู่ split เดียวกัน
- COCO: val2017 ไม่อยู่ในชุดเทรนของ yolo11 pretrained จึงใช้วัดโมเดลเดิมได้ยุติธรรม
  ภาพที่มีมีด/กรรไกร แบ่ง 40% train / 10% val / 50% test
- เลือก threshold บน **val** แล้วรายงานบน **test** ครั้งเดียว

## 5. การเทรน (`tools/train_hazard_model.py`)

- เริ่มจาก `yolo11n.pt` (COCO), SGD lr0 0.002 (ต่ำกว่าค่าปกติ 5 เท่า: fine-tune ไม่ใช่เทรนใหม่)
- `scale 0.9` (ค่าปกติ 0.5): สุ่มย่อวัตถุลงเหลือ 10% ให้โมเดลเห็นของชิ้นเล็ก = ของที่อยู่**ไกลกล้อง**
- Colab: imgsz 960, ปลด backbone (freeze 0), 40 epochs, ภาพเทรน 7,572 ภาพ
- CPU (สำรอง): imgsz 640, freeze 10, 10 epochs, ภาพเทรน 3,712 ภาพ

## 6. วิธีวัด (`tools/eval_hazard_model.py`)

- AP50 ต่อคลาส + ช่วงความเชื่อมั่น 95% (bootstrap 1,000 รอบ)
- **ระดับภาพ** (ตรงกับการแจ้งเตือน): hazard recall และอัตราแจ้งผิดในภาพที่ไม่มีของมีคม
- **recall แยกขนาดวัตถุ** small < 3% ของภาพ (≈ ของในมือห่าง 3–4 ม.), medium 3–8%, large > 8%
- ผลต่างระหว่างโมเดลใช้ **paired bootstrap** อ้างว่า "ดีขึ้น" ได้ก็ต่อเมื่อช่วงความเชื่อมั่นของผลต่างไม่คร่อม 0
