# สคริปต์ถ่ายคลิปทดสอบสำหรับ QA

คลิปชุดนี้ใช้วัดผล "ก่อน → หลัง" ของทุก module ด้วย `tools/eval_clips.py`
ถ้าตั้งชื่อไฟล์ผิด เครื่องมือจะข้ามคลิปนั้น จึงต้องตั้งชื่อตามข้อ 3 ทุกไฟล์

## 1. กฎความปลอดภัยและความเป็นส่วนตัว (ต้องทำตามทุกข้อ)

- ใช้**ผู้ใหญ่ที่ยินยอมเท่านั้น** ห้ามถ่ายเด็ก ให้ผู้ใหญ่ย่อตัวหรือนั่งยองแทนความสูงของเด็ก (ต้องเขียนในรายงานว่าใช้ผู้ใหญ่แทน)
- **ทะเลาะวิวาท:** เป็นการแสดงเท่านั้น ผลักหรือตีเบา ๆ ไปทางลำตัว ห้ามโดนหน้า ห้ามใช้แรงจริง หยุดทันทีถ้ามีใครไม่สบายใจ
- **ปีนป่าย:** ใช้เก้าอี้หรือม้านั่งที่สูงไม่เกิน 40 ซม. และมั่นคง มีคนยืนประกบทุกครั้ง ห้ามปีนโต๊ะหรือชั้นวางจริง
- **ของมีคม:** ใช้กรรไกรจริง (ตามกฎ Decision Gate ห้ามใช้ภาพจากจอหรือกระดาษ) ห้ามชี้กรรไกรเข้าหาคน ไม่ต้องใช้มีดถ้าไม่มี
- **สูบบุหรี่:** **ห้ามสูบจริง** ใช้บุหรี่ปลอม เช่น กระดาษขาวม้วนยาวประมาณ 8 ซม. แล้วบันทึกในรายงานว่าใช้ของปลอม
- ห้ามเผยแพร่คลิป ห้ามอัปโหลดขึ้นรีโป เก็บในเครื่องเท่านั้น และลบเมื่อจบโปรเจกต์

## 2. การตั้งกล้อง

- **กล้องหลัก:** ใช้กล้องของ Mac เครื่องเดโม อัดด้วย QuickTime (File → New Movie Recording) ตั้งในตำแหน่งเดียวกับวันเดโม จะได้ภาพมุมเดียวกับที่ระบบเห็นจริง
- **กล้องที่สอง (ถ้ามีเวลา):** ใช้มือถือ ถ่ายแนวนอน 1080p 30fps วางนิ่งบนขาตั้งหรือกองหนังสือ ระดับสายตาหรือสูงกว่าเล็กน้อย ห้ามถือด้วยมือ
- **ห้ามเปลี่ยนตำแหน่งกล้องระหว่างคลิปในรอบเดียวกัน** ถ้าต้องย้าย ให้ถ่ายคลิปปรับเทียบโซนใหม่ (ข้อ 5)
- เห็นตัวคนเต็มตัวตั้งแต่หัวถึงเท้า ยกเว้นคลิปที่ระบุไว้
- ห้ามใส่ฟิลเตอร์ ห้ามซูมระหว่างถ่าย ห้ามตัดต่อ (ตัดหัวท้ายได้อย่างเดียว)
- แต่ละคลิปยาว **10–20 วินาที** ให้ฉากว่าง 2 วินาทีแรก แล้วค่อยเริ่มทำท่า
- ท่าที่ควรแจ้งเตือน (pos) ต้อง**ทำค้างหรือทำซ้ำอย่างน้อย 5 วินาที** เพราะระบบต้องเห็นต่อเนื่องก่อนยืนยัน (ออกนอกพื้นที่ 3 วินาที, ทะเลาะ 1 วินาที)

## 3. การตั้งชื่อไฟล์

```
<module>_<pos|neg>_<รอบ>_<ลำดับ>_<คำอธิบายสั้น>.mp4
```

- `module`: `hazard` (ของมีคม), `smoking`, `fight`, `climbing`, `outarea` (ออกนอกพื้นที่), `normal` (กิจกรรมปกติ)
- `pos` = ควรแจ้งเตือนเรื่อง module นั้น, `neg` = ไม่ควรแจ้งเตือนอะไรเลย (`normal` เป็น `neg` เสมอ)
- `รอบ`: `s1`, `s2`, ... ใช้ตัวพิมพ์เล็ก ภาษาอังกฤษ ห้ามมีเว้นวรรค
- คลิปจาก QuickTime เป็น `.mov` ได้ ไม่ต้องแปลงไฟล์

## 4. แบ่งรอบ: ชุดปรับค่า (s1) กับชุดวัดผล (s2)

| รอบ | ใช้ทำอะไร | ข้อกำหนด |
|---|---|---|
| **s1** | **ปรับค่า** (tune) | ถ่ายวันอาทิตย์ หรือเช้าวันจันทร์ |
| **s2** | **วัดผล "ก่อน" และ "หลัง"** (test) | ถ่าย**ต่างเวลา** ใช้**คนอื่น**หรือเปลี่ยนเสื้อผ้า และแสงต่างจาก s1 ให้มากที่สุด |

ห้ามนำคลิป s2 ไปใช้ปรับค่า ไม่อย่างนั้นตัวเลข "หลัง" จะเชื่อไม่ได้

## 6. หลังถ่ายเสร็จ

1. ย้ายไฟล์ทั้งหมดไปที่ `~/qa_clips/` บน Mac เครื่องเดโม (ชื่อโฟลเดอร์ห้ามมีเว้นวรรค และห้ามใส่ไว้ในรีโป)
2. ให้อีกคนเปิดดูทุกคลิปว่าตรงกับชื่อไหม ถ้าคลิปไหนไม่ตรง ให้เปลี่ยนชื่อหรือลบ
3. สร้างไฟล์ป้าย:
   ```bash
   python tools/eval_clips.py --init-labels ~/qa_clips --labels docs/eval/qa_labels.csv --tune-sessions s1
   ```
4. เปิด `docs/eval/qa_labels.csv` ตรวจอีกครั้ง ถ้าเหตุการณ์ในคลิปไม่ชัด ให้เขียนลงคอลัมน์ `note`

## 7. เวลาที่ใช้โดยประมาณ

ต่อ 1 รอบ: 47 คลิปสั้น ประมาณ 2 ชม. รวมจัดฉาก และคลิปปกติ 2 คลิปประมาณ 20 นาที
ถ้าเวลาไม่พอ ให้ทำตามลำดับนี้ก่อน: กิจกรรมปกติ → smoking neg → fight → outarea → hazard → climbing
